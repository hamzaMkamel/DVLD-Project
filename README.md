# Driving Vehicle License Department Project

- A Desktop Application is used to Issue Driving Licenses and the ability to make Full management of the Licenses
# Features
## People Management 

- manage people on the system (adding , deleting , editing ,etc..)
## Users Management

- The ability to add users and the login process management
## Drivers Management

- manage the people whose already has been Issued Licenses to them
## Local Driving Licenses

- Issue Local Driving License
- Schedule Tests Appointments
- Renew License 
- Lost or Damaged License Replacement
- Manage The License
## Driving Tests Management

- Vision , Written and street test management
- Storing the results
## International Driving Licenses
- Issue International Driving License
- Manage International License
## Detain & Release Licenses
- Detain Licenses and store the fees
- Release the License after the the driver paid the fees
## Applications Management
- Manage the Different applications
- preview the application status
- Sequence of Tests
# Technologies 
- C#
- SQL Server
- Windows Forms
- ADO.Net
- OOP
- Three Tier Architecture
  - Presentation Layer
  - Business Logic Layer
  - Data Access Layer
- User Controls
